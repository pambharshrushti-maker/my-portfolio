## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/pambharshrushti-maker/my-portfolio.git
```

### 2. Open the Project

```bash
cd my-portfolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run the Project

```bash
npm run dev
```

The project will run on the local development server provided by **Vite**.
